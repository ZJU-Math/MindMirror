# MindMirror v0.1.0 测试版

版本：v0.1.0 · Pre-release（测试版）。发布日期：2026-10-27。

## 版本内容与状态

本版本提供上传分析、实时观察通道、引导式任务、报告与历史记录等测试功能。输出用于观察和研究评估参考，不构成医学诊断。

基础流程已有 Windows / macOS 测试记录，但已知缺陷尚未修复，不能作为稳定版验收通过。本次仅整理分发资料，没有修改软件或模型。

## 平台与安装

- macOS：arm64 / M 系列芯片；安装器要求 macOS 14+。应用 Info.plist 最低字段写 13.0，与安装器要求不一致，不据此承诺支持 macOS 13。已有 macOS 15.8.1 原始应用载荷测试，尚未执行完整 PKG 安装、覆盖和卸载验收。
- Windows：安装后主程序和运行时为 x64，已有 Windows 10 19045 x64 标准用户安装与基础流程测试记录。Windows 11、全新无运行库系统等场景仍待验证。
- 签名：Mac 安装器无签名、原始应用签名校验未通过；Windows 安装器和主程序未签名。不能保证下载后无系统安全提示。

详见[安装与使用](../docs/安装与使用.md)。

## 已知问题

# 观心 MindMirror

用于面部行为观察、引导式任务与报告查看的桌面测试软件。输出用于观察和研究评估参考，不构成医学诊断。

本项目提供版本说明、安装指南、更新记录及历史版本索引。当前版本为 **v0.1.0 测试版**，基础分析流程已有双平台测试记录，仍存在已知问题，不作为稳定版提供。

## 主要功能

- 上传视频或图片，查看面部行为观察结果。
- 摄像头实时观察通道与引导式任务。
- 观察报告、问卷及历史记录界面。
- 本地语音引导和可选外部服务配置。

功能存在不等于全部场景完成验收。当前视线校准、时长统计和重启后历史显示等问题详见已知问题说明。

## 隐私与使用范围

本地分析与可选联网功能应分别看待。部分语音、外部大模型及第三方依赖可能涉及网络访问；未经专项核对，不能承诺所有功能完全离线或绝无外联。启用外部服务前，请确认发送内容和适用许可。

不建议将唯一一份重要资料保存在测试版中。更新前备份数据，勿将旧版本留存理解为数据一定能够直接降级。

# v0.1.0 已知问题与测试边界

依据 2026-10-26 的 Mac 测试报告及 Windows 回传审阅整理。以下问题尚未修复，测试版不能作为稳定版验收通过；流程可运行不代表模型准确率或医学效度已验证。

| 问题 | 对使用的影响 |
|---|---|
| MM-01 视线校准有效性 | 校准未完成时，部分视线数值仍可能进入报告和任务；请勿据此作有效测量判断。 |
| MM-02 有效时长统计 | 24/25 fps 等采样场景可能低估有效观察时长，影响覆盖比例和频率分母。 |
| MM-03 重启历史显示 | 桌面后台换端口后，历史列表可能为空。已有测试中数据库记录仍在，属于访问身份关联问题，不能直接判为数据删除。 |
| MM-04 退出与重试 | 分析中主动退出可能消耗失败重试预算；多次中断有任务失败风险。 |
| MM-05 时长标签 | 部分界面将总时长标为有效时长，需结合当前版本限制理解。 |
| MM-06 参考范围措辞 | 工程暂定观察带被写成文献参考范围；不能视为已完成整套范围验证。 |
| MM-07 签名与发行 | 两个平台的发行签名尚未完成，Mac 应用签名校验未通过。 |
| MM-08 随包说明 | 旧说明中的脚本启动和部分语音描述与当前桌面包不一致，以项目版本说明为准。 |

视线和计时问题包含受控输入复现，并非相应数量的自然录像失败案例。当前没有修改软件或重新打包。

- Mac：原始 PKG 载荷在 macOS 15.8.1 arm64 运行，上传分析、接口、核心/设置/协议、实时通道及部分媒体流程已有记录；未执行完整安装器落盘流程。
- Windows：回传记录覆盖 Windows 10 19045 x64 安装、原包依赖导入、上传分析、接口、核心/设置/协议、实时通道、部分后台媒体与本地语音流程。
- 同一测试验证了基础流程，也复现了已知问题；不能只用通过项概括整个版本质量。

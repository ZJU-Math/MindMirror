# 安装与使用

适用版本：v0.1.0 测试版。安装包通过 [v0.1.0 Release](https://github.com/ZJU-Math/MindMirror/releases/tag/v0.1.0) 提供；请先阅读[已知问题](已知问题.md)。

## 选择安装包

| 电脑 | 文件 | 平台范围 |
|---|---|---|
| Mac / M 系列芯片 | `MindMirror-0.1.0-mac-arm64.pkg` | 安装器要求 macOS 14+；已有 macOS 15.8.1 载荷运行记录 |
| Windows / x64 | `MindMirror-0.1.0-win-x64.exe` | 已测试 Windows 10 19045 x64；其他系统待验证 |

Intel Mac 暂无对应包。不要将 GitHub 自动生成的 `Source code` 文档快照当作安装程序。

## 校验下载

对照[版本说明](../releases/v0.1.0.md)或同版 `SHA256SUMS.txt` 核对 SHA-256。GitHub 与云盘附件应完全相同。

macOS 终端示例，将路径替换为实际下载位置：

```sh
shasum -a 256 "$HOME/Downloads/MindMirror-0.1.0-mac-arm64.pkg"
```

Windows PowerShell 示例：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "$env:USERPROFILE\Downloads\MindMirror-0.1.0-win-x64.exe"
```

## 安装与启动

macOS：双击 `.pkg` 并按安装器提示操作。当前完整 PKG 安装、覆盖与卸载仍待验收，不将载荷启动测试当作安装器验证。

Windows：双击 `.exe` 并按安装器提示选择位置、完成安装；再从创建的应用入口启动。已有 Windows 10 隔离目录安装测试，不代表覆盖安装、中文路径、卸载或全新系统已通过。

首次启动需要加载本地服务和模型，可能需要等待。当前两端均存在签名问题，系统可能提示无法验证发布者或阻止运行。请核对文件来源、校验值及发布方说明，勿关闭系统整体安全保护。

包内旧 `.command` / `.bat` 与浏览器启动说明不适用于当前 Electron 桌面安装方式。

## 权限与数据

主动使用摄像头或麦克风功能时再授予相应权限。完整设备任务链路尚未验收，具体可用性需在自己的设备确认。

本地分析与可选联网功能分开看待。外部大模型配置可能发送报告上下文；部分语音和第三方依赖的网络范围需要另行核对。不要公开配置文件、API 密钥、私人视频或报告。

升级前备份重要资料。历史列表为空不等于文件已删除；v0.1.0 已知换端口身份问题可能影响显示，遇到问题先停止重复上传或删除数据并联系维护者。确切数据目录应按当前安装环境确认，勿直接套用旧脚本包路径。

旧安装包留存不代表数据能够直接降级，未验证兼容性前不承诺无损回退。

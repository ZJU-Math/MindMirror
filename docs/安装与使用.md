# 安装与使用

适用版本：v0.1.0

## 1. 下载与安装

### Windows

适用于 Windows 10（64 位）。

1. [下载 Windows 安装包](https://github.com/ZJU-Math/MindMirror/releases/download/v0.1.0/MindMirror-0.1.0-win-x64.exe)。
2. 双击 `.exe` 文件，按安装向导完成安装。
3. 在开始菜单中搜索 MindMirror，或从安装目录打开软件。

### Mac

适用于 macOS 14 及以上、搭载 Apple Silicon（M 系列芯片）的 Mac。

1. [下载 Mac 安装包](https://github.com/ZJU-Math/MindMirror/releases/download/v0.1.0/MindMirror-0.1.0-mac-arm64.pkg)。
2. 双击 `.pkg` 文件，按提示继续并完成安装；如系统要求，输入电脑的管理员密码。
3. 在“应用程序”中打开 MindMirror。

安装包已包含运行环境和模型，无需另装 Python。首次启动需要加载模型，请等待首页出现后再开始操作。

版本页中的 `Source code` 是项目文档压缩包，安装软件请选择 `.exe` 或 `.pkg`。

## 2. 分析视频或图片

1. 打开“上传分析”。
2. 选择电脑中的视频或图片，按页面提示提交。
3. 等待分析完成，打开结果查看回放和观察报告。

建议先使用常见的 MP4 视频或 JPG、PNG 图片。画面尽量清晰，人脸无遮挡，并保持光线均匀；较长的视频需要更多处理时间。

## 3. 使用摄像头实时观察

1. 打开“摄像头实时”，选择“自由观察”。
2. 按提示允许软件使用摄像头。
3. 调整坐姿、距离和光线，让面部清楚地出现在画面中，再开始观察。
4. 结束时，按页面提示选择是否保存本次结果。

如果需要接入网络摄像头，可进入“监控”，填写设备提供的 RTSP 地址并按界面提示连接；电脑需要能够访问该设备。

## 4. 完成引导式任务

1. 在“摄像头实时”中选择“引导式任务”，再选择要进行的任务。
2. 根据准备检查调整位置和光线；涉及语音的任务还需允许使用麦克风。
3. 播放试音，确认能够听见提示，然后开始任务。
4. 按屏幕和语音提示完成互动，结束后查看或保存结果。

引导声音可在任务准备页选择，音量也可在此调整。

## 5. 查看报告与记录

在“我的分析”中打开已保存的记录，可继续查看回放与报告。报告中包含观察结果和相关说明；需要补充问卷时，按页面提示填写。

观察结果用于辅助参考，不能单凭分数或某一项指标判断健康状况。

## 6. 可选设置

基础分析无需填写外部大模型密钥。如需使用外部大模型生成解读，可在“设置”中填写服务地址、模型名称和 API 密钥。

图像与视频的基础分析在本机运行。在线语音和外部大模型需要联网，并会向你选择的服务发送相应称呼或报告内容；请按自己的需要选择。

## 7. 常见使用问题

**首次打开等待较久**：首次启动会加载本地模型。请等待首页出现，避免反复打开多个窗口；若停留在加载页，可使用页面提供的重启或日志入口，并将错误提示反馈给维护者。

**摄像头没有画面或麦克风没有声音**：确认设备已连接、没有被其他软件占用，并检查系统权限。Mac 在“系统设置 → 隐私与安全性 → 相机／麦克风”中查看；Windows 在“设置 → 隐私 → 相机／麦克风”中查看。

**视频无法分析或回放**：先用较短的 MP4 视频尝试。反馈时说明文件格式、时长和出现问题的步骤，无需公开上传私人视频。

**安装或首次打开时出现系统提示**：确认安装包来自本项目，按系统提示处理；若仍无法打开，可将提示截图提交到 [Issues](https://github.com/ZJU-Math/MindMirror/issues)。

## 8. 备份、更新与卸载

更新前先退出 MindMirror，备份需要保留的记录。默认数据文件夹为：

- Windows：`%APPDATA%\MindMirror`
- Mac：`~/Library/Application Support/MindMirror`

可以将整个文件夹复制到其他位置保存。更新时从项目页下载新版本并按新版本说明安装，历史安装包保存在[历史版本](历史版本.md)中。

卸载时，Windows 可使用系统“应用和功能”，Mac 可在“应用程序”中移除 MindMirror。如需一并清除本地资料，请在退出软件并完成必要备份后，再删除相应数据文件夹。

## 9. 联系与反馈

通过 [Issues](https://github.com/ZJU-Math/MindMirror/issues)提供软件版本、电脑系统、操作步骤及错误提示。公开反馈请勿附带私人录像、个人报告或 API 密钥。
